# Description


Just a simple mod selling your excess weapons/LPCs whenever you land at a matching market.
Makes keeping e.g 25 of all weapons and LPC around to fit ships however you like easy, while automatically trimming the stockpile.
The market price stuff I'm not completely sure about, but I mean, this is mostly later game, and the credits shouldn't matter too much.

Config is done in the mod menu from LunaLib, F3 in game or on the main menu.
If you don't have/don't run it, it will read from the "data/config/weaponAmountsSettings.json" file and work fine, 
you just can't use the modmenu to turn it on/off and edit the threshold in game.
